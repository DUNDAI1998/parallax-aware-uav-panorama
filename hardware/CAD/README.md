# CAD file

`panoramic_uav_assembly_v1.step` is an AP242 STEP assembly using millimetres. Verify its SHA-256 value against `SHA256SUMS` after downloading.

The public copy removes local export paths and authoring metadata from STEP descriptive fields. Geometry, product hierarchy, and assembly relationships are retained.

The file should be treated as a reference assembly. Before fabrication, independently inspect interferences, tolerances, fasteners, center of gravity, propeller clearance, electrical isolation, thermal paths, and vibration behavior.

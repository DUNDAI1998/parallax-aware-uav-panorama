# Dataset access

The raw fisheye flight data are hosted separately from this code repository.

Dropbox download link: **to be added after the public data package is uploaded**

The public data package should include:

- a manifest of synchronized four-view groups;
- scene and sequence metadata;
- the applicable data license and privacy notice;
- `SHA256SUMS` for archive verification;
- no unreviewed personal identifiers or unnecessary flight logs.

Do not use the paper's quantitative results as ground truth for a newly downloaded subset unless the manifest and evaluation split match the stated protocol.
